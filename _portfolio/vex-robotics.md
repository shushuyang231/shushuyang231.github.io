VEX V5 机器人控制代码，基于上海交通大学巴黎卓越工程师学院（SPEIT）VEX 机器人社团招新培训框架，在此基础上完成了机器人硬件配置、遥控驾驶逻辑与自动赛策略的实现（2025 年秋季）。涵盖四电机差速驱动、摇杆死区与慢速切换、传送带与发射器机构控制，以及预编程自动赛路径——为机器人嵌入式编程的入门实践。

VEX V5 robot control code built on the SPEIT VEX robotics club training framework, with custom implementation of hardware configuration, driver control logic, and autonomous routines (Fall 2025). Covers four-motor differential drive, joystick dead zones and speed switching, intake/launcher mechanism control, and pre-programmed autonomous paths — an entry-level practice in embedded robot programming.

**Tech:** C++ (VEXcode V5)
