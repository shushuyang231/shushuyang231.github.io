A cross-benchmark empirical study that applies mutation testing to task-scoped state oracles, measuring how well benchmarks detect unintended side effects and calibrating oracle reliability across software-agent evaluation suites. Code is available in the [side-effect-calibration-study](https://github.com/shushuyang231/side-effect-calibration-study) repository.
